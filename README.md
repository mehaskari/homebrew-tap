# mehaskari/homebrew-tap

Homebrew formulae for [xping](https://github.com/mehaskari/xping), beautiful
CLI network diagnostics.

```bash
brew install mehaskari/tap/xping
```

or

```bash
brew tap mehaskari/tap
brew install xping
```

The man page (`man xping`) and tab completion for bash, zsh and fish are
installed with it.

The formula follows the releases on PyPI: a daily workflow updates it when
a new xping version is published, after building and testing it on macOS.
